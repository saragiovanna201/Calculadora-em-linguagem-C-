# 🧮 Calculadora em C

Uma calculadora de linha de comando desenvolvida em linguagem C, criada como 
projeto de estudo para praticar lógica de programação, feita em grupo com funções matemáticas 
e manipulação de entrada/saída de dados.

## 📋 Funcionalidades desenvolvidas

- ➕ Soma
- 🔢 Fatorial de um número
- 📐 Cálculo de tangente
- 🔄 Conversão de radianos para graus

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca `math.h`
- Compilador GCC

## 🧠 O que aprendi com esse projeto

- Uso de `scanf`/`printf` com diferentes tipos de dados
- Estruturas condicionais e laços de repetição
- Funções matemáticas da biblioteca `math.h`
- Recursão (na função de fatorial)
- Organização de código em funções reutilizáveis
